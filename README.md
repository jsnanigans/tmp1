# Food Analysis Coding Challenge

The brief is in **[CHALLENGE.md](CHALLENGE.md)**. Read it before the session.

- `CHALLENGE.md` — the task, requirements and how the session runs
- `assets/test-images/` — sixteen CC0 / public-domain test images with opaque filenames
- `assets/edge-cases/` — unusual and invalid inputs to exercise error handling
- `.env.example` — copy to `.env` and add the API key we send you at the start

## Before the call

- Have an editor, a runtime and a package manager ready for your chosen stack.
- Confirm you can start a "hello world" web server and open it in a browser.
- Do not build the solution in advance. Setup only.
